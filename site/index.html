YouTube, without the tracking.

A single-maintainer fork of FreeTube, the open-source desktop client that keeps your subscriptions, history and settings on your own machine. This fork fixes long-standing bugs directly and ships the OLED black theme by default.

DownloadView source

Private by design

No Google account, no ads, no telemetry. Subscriptions and playlists live in local databases you can export at any time.

Tracks upstream

Upstream changes and translations are merged in regularly; this fork adds bug fixes on top and stays close to upstream's code.

Every platform

Windows, macOS and Linux, each as x64 and ARM64 builds, with a SHA256 checksum for every file.

Good to know

  • Not the official build. For FreeTube from its own team, go to freetubeapp.io. Please report problems with these builds on this fork, not upstream.
  • macOS: builds are ad-hoc signed, not notarised. On first launch, right-click the app and choose Open, or allow it under System Settings > Privacy & Security.
  • Your data: the fork reads the same profile directory as official FreeTube, so it opens your existing subscriptions. Back up the profile first if you plan to switch between the two.
  • How to use FreeTube: see upstream's user documentation.
